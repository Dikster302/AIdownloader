Политика конфиденциальности

Дата вступления в силу: 26 ноября 2026 г.

1. Кто мы
AIdownloader — веб-сервис для поиска и скачивания видеоматериалов по текстовому описанию. Сервис использует открытый API Pixabay (pixabay.com) для поиска видео.

2. Какую информацию мы собираем
При авторизации (через Google или Apple) мы получаем:

  • Ваш email-адрес
  • Ваше имя (если предоставлено)
  • URL аватара (если предоставлен)

При использовании сервиса локально в вашем браузере сохраняется:

  • История поисковых запросов (не более 30 записей)
  • Настройки сортировки

3. Как мы используем информацию

  • Для персонализации поиска и отображения истории
  • Для соблюдения требований Pixabay API
  • Для предотвращения злоупотреблений (ограничение частоты запросов)

4. Передача данных третьим лицам
Ваш поисковый запрос и API-ключ передаются напрямую в Pixabay.com для получения результатов. Аутентификация происходит через Google (Firebase) и Apple. Мы не продаём и не передаём данные третьим лицам, кроме как для работы сервиса.

5. Cookies и локальное хранилище
Мы используем localStorage браузера для хранения настроек. Cookies применяются Firebase для сессии авторизации. Аналитический трекинг не ведётся.

6. Защита данных
Данные авторизации защищены на инфраструктуре Google Firebase. API-ключ Pixabay хранится на стороне клиента и защищён лимитами запросов.

7. Ваши права
Вы можете:

  • Выйти из аккаунта в любой момент
  • Очистить историю поиска в настройках браузера
  • Запросить удаление аккаунта: напишите support@aidownloader.app
  • Отозвать согласие через настройки Google/Apple аккаунта

8. Возрастные ограничения
Сервис предназначен для лиц от 13 лет. Для пользователей младше 13 лет требуется согласие родителя/опекуна.

9. Изменения политики
Мы можем обновлять настоящую политику. О значимых изменениях уведомим на этой странице. Продолжение использования сервиса означает согласие с новой редакцией.
